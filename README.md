# SEDS lab 4: Git basics

A practice repository from lab 4 of the SEDS course, used to practise the basic Git workflow and publish the result on GitHub.

## What it contains

The history has three commits, one per step:

| Commit                                       | Step                                              |
| -------------------------------------------- | ------------------------------------------------- |
| `first commit`                               | Create the repository with `first.py`             |
| `scond commit`                               | Add a second file, `scond.py`                     |
| `Add variable x with value 123 in scond.py`  | Edit a tracked file and commit the change         |

```bash
git clone https://github.com/ay-boutera/seds-lab4.git
cd seds-lab4
git log --oneline
```
